Our projects build practical systems for immersive computing, extended reality, human-AI interaction, mobile/edge/cloud infrastructure, and privacy-preserving spatial computing.

## Active Projects

### CoMIC

**Status:** Active  
**Type:** Multi-user XR infrastructure

CoMIC is a collaborative mobile immersive computing infrastructure for conducting multi-user XR research. The project supports experimentation with shared immersive environments, multi-user interaction, and networked XR system behavior.

**Related research areas:** multi-user XR, mobile immersive computing, collaborative systems, XR infrastructure.

### OpenCIVAN

**Status:** Active  
**Type:** Open-source ecosystem, collaborative immersive analytics, scientific visualization

OpenCIVAN is an open-source ecosystem for collaborative immersive visualization and analytics of high-dimensional scientific data. The project studies how domain experts can jointly explore complex scientific datasets using immersive environments, shared views, annotations, provenance, and cross-device collaboration.

**Related research areas:** multi-user XR, immersive analytics, scientific visualization, collaboration, open-source systems.

**Student contributors:** Fahim Arsad Nafis and collaborators

**Related publication:**  
Exploring Collaborative Immersive Visualization & Analytics for High-Dimensional Scientific Data through Domain Expert Perspectives, ACM CHI 2026.

Links: GitHub | Demo | Documentation

### Volumetric Streaming Systems

**Status:** Active  
**Type:** Immersive content delivery

This project investigates efficient systems for capturing, representing, delivering, and rendering volumetric video and 6DoF immersive content. The work focuses on bandwidth efficiency, latency reduction, perceptual quality, neural content representation, and multi-user volumetric streaming.

**Related research areas:** volumetric video, 6DoF streaming, neural representation, semantic communication, mobile XR.

**Representative publications:** NeVo, MuV2, MetaStream, Vues, YuZu, ViVo.

Links: Project page | Demo videos | Publications

### Privacy-Preserving XR

**Status:** Active  
**Type:** Privacy, security, spatial computing

This project develops privacy-preserving techniques for immersive applications that rely on sensing, localization, user authentication, and spatial understanding. The goal is to support useful XR functionality while reducing exposure of sensitive user and environment data.

**Related research areas:** XR privacy, 6DoF localization, spatial mapping, authentication, federated learning.

**Representative publications:** PIPE, MetaFL, Preserving Privacy in Mobile Spatial Computing.

Links: Project page | Code

### Human-GenAI Interaction Systems

**Status:** Active  
**Type:** Human-AI interaction, measurement, communication systems

This project studies how people interact with generative AI systems in communication and collaboration settings. The work examines system behavior, user interaction patterns, platform design, and future opportunities for AI-mediated communication.

**Related research areas:** human-AI interaction, generative AI, communication systems, measurement.

**Representative publication:** Hello, GenAI? Dissecting Human to Generative AI Calling, ACM IMC 2025.

### Browser-based XR and Web Acceleration

**Status:** Active  
**Type:** Web systems, browser acceleration, immersive platforms

This project examines the performance of browser-based acceleration technologies for immersive and AI-enabled applications. The work studies WebAssembly, WebGPU, WebGL, and web-based mobile extended reality.

**Related research areas:** WebXR, WebAssembly, WebGPU, browser systems, performance measurement.

**Representative publications:** From WebGL to WebGPU, Demystifying Web-based Mobile Extended Reality Accelerated by WebAssembly.

## Completed / Foundational Projects

### 360-degree Video Streaming

This foundational project studied bandwidth-efficient 360-degree video streaming for mobile devices. It contributed to viewport-adaptive streaming, viewport prediction analysis, live 360-degree video measurement, and ultra-high-resolution panoramic video delivery.

### Network Management and Automation

This foundational project studied network functions virtualization, service function chaining, traffic management, and network automation.

### Mobile Opportunistic Networks and WiFi Systems

This foundational work studied mobile opportunistic communication, cellular traffic offloading, multipath networking, energy-efficient device discovery, and WiFi performance.
